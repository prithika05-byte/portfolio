Book Donation Management System

📚

Project Overview

The Book Donation Management System is a web-based application developed to connect book donors with students who need books. It provides a simple platform where donors can donate books and students can search, request, and receive books without any cost. The system also includes dashboards for donors and receivers, notification management, approval tracking, and feedback features to improve transparency and user experience.
